# Code conventions

- Always write code in English, including identifiers, file names, routes, CSS classes, structured data keys, and code comments.
- Keep user-facing copy and source event content in their intended language.
- Before adding a new component, check whether an existing one can be reused. Choose a name that makes sense across all of its use cases.
- Cover application behavior with automated tests.
- Before finishing any change, verify it directly in the Rails test environment. Prefer system tests when they can exercise the changed behavior.
