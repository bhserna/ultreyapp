# Temas para preguntas generales

Ahora una pregunta "general" va a poder tener un tema.

En la página de "Preguntas generales", vamos tener un sidebar  para temas.
"Temas".

Los temas van a tener una interfaz similar a la de preguntas, pero pues solo con un campo. Debe ser un CRUD completo.

Debemos validar que el nombre exista, pero solo en la base de datos y forzarlo por validación de html.

Este sidebar se va a comportar como "Tabs", y si una de esos temas está seleccionada las preguntas que se creen, estarán relacionadas
a ese tema.

Debe haber una columna de fault "Sin tema" (o si se te ocurre un nombre mejor podemos cambiarlo).
